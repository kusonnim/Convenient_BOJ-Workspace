To recover into a **new** directory, run the following from the original checkout. The bundle can also be copied independently. To inspect the exact former local state, extract the Git ZIP into an empty directory and pass that directory to `git --git-dir`.

```powershell
git clone --mirror backups/p3.5-pre-migration/all-refs.bundle p35-recovered.git
git --git-dir=p35-recovered.git fsck --full --strict
git --git-dir=p35-recovered.git rev-parse refs/heads/codex/p3-clangd
```

The last command should print `a0e8d4661d3eb64ccd4330b7d8100e690d9eeba7`. The GitHub backup predates P3. Use the bundle or the fork's P3 branch for that commit.

## Regression results

The suites ran sequentially on Windows using the installed Chrome, registered native host, CPython 3.14.3, x64 MSVC, GCC/G++ 16.2.0 and clangd. Chrome loaded the unpacked extension in disposable profiles. The fixture intercepted BOJ problem, manual prefill, judging and polling requests locally. Wandbox responses were doubled. The run made no live BOJ or Wandbox submission.

| Suite | Command | Observed result |
| --- | --- | --- |
| Native P0 | `python -B tests/p0/native_test.py` | 9 passed. Zero job directories remained on disconnect. |
| Native P1 | `python -B tests/p0/native_p1_test.py` | 10 passed, including MSVC/GCC cache identity, legacy host, timeout and descendant cleanup. |
| Native P3 | `python -B tests/p0/native_p3_test.py` | 7 passed, including real clangd, GNU headers, forced exit, stale packets and isolated uninstall. |
| Chrome P0 | `npm.cmd --prefix tests/p0 test` | 8 passed. The expected failure reproduced the first pending form closing when the second opened. |
| Chrome P1 | `npm.cmd --prefix tests/p0 run test:p1` | 5 passed with real local execution and controlled compatibility and consent replies. |
| Chrome P2 | `npm.cmd --prefix tests/p0 run test:p2` | 7 passed, including legacy drafts, worker cleanup, browser IME and local MSVC. |
| Chrome P3 | `npm.cmd --prefix tests/p0 run test:p3` | 5 passed, including STL completion, UTF-16, server recovery, independent analysis sessions and fallback. |

All seven commands exited 0 with zero skips or retries. Playwright includes the expected failure in its summary for P0. Each browser command used a fresh `--output` directory. The local transcripts are under `tests/p0/measurements/p35/`. Authenticated BOJ submission and the owner's external Git integration remain owner-initiated checks. Full installation and lifecycle hardening is scheduled for P4.
