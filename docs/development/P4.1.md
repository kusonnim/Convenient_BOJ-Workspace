## User-visible changes

| Feature | Behavior and defaults |
| --- | --- |
| Themes | Light+ remains the fresh-profile default. The picker also offers Dark+, One Dark, Dracula, Monokai, Nord, GitHub Dark and Tokyo Night. Existing `light` and `dark` values retain their meaning. Each palette covers syntax, suggestions, diagnostic markers, terminal and sample output, scrollbars and workspace controls. The native statement keeps its original DOM and computed colors. |
| Personalization | The popup persists font family, size from 10–32 px, line height from 12–56 px and minimap visibility. Defaults are D2Coding, Cascadia Code, Consolas and monospace in order, 14 px type, 22 px lines and minimap off. Existing template, indentation and compiler settings carry forward. |
| Editing | Native Sticky Scroll starts on, uses indentation scopes and shows at most three lines. Bracket colorization and active horizontal and vertical pair guides start on. Occurrences and breadcrumbs start on. Wrap starts off. Alt+Z toggles and saves it. Settings apply to open editors. |
| Navigation | The compact bar shows the language, virtual file and nested symbols at the cursor. Click a symbol to browse siblings or the file to see the outline. Arrow keys, Home, End, Escape and the focused button support keyboard navigation. Selecting a declaration focuses its UTF-16 location. Filled read/write highlights come from clangd. Dashed word matches, including matching text in comments, identify Monaco’s textual fallback. |
| Formatting | Shift+Alt+F and Monaco’s Format Document command explicitly format the current C or C++ buffer. Local clang-format uses LLVM style, four columns and the current tabs/spaces preference. One undo restores the original text. Formatting probes the host before sending the draft, checks model version and composition state, and caps input/output at 512 KiB and execution at six seconds. |
| Local execution | Sample and interactive time limits are separate, defaulting to 10 and 120 seconds. Each accepts whole seconds from 1 through 300. Existing native process-tree timeout, cancellation, cache and compiler selection supply execution. Remote runs retain their provider behavior. |
| Compiler messages | The draft’s own `main.c` and `main.cpp` errors and warnings in the local terminal carry clickable locations. Header paths and program output stay plain text. Edits or document switches invalidate a link. MSVC `/diagnostics:column` and GCC 11+ byte-column output map to Monaco UTF-16 positions. MSVC guidance is tied to actual GNU-header or `__int128` diagnostics and preserves the compiler’s original message. |
| Local tools | Clangd discovery also checks per-user LLVM, WinGet package layouts and an additional VS Code extension layout. The popup links to clangd installation guidance. A reconnect button reopens analysis on request, alongside P3’s bounded crash retries. Missing tools leave editing, basic completion and file breadcrumbs usable. |
| Backup | The popup downloads a versioned local JSON file for drafts, templates, editor and execution preferences, layout and compiler choice. Export reads the current open buffers, including unsaved text. Divergent tabs editing the same draft require separate preservation. Restore validates the entire file (32 MiB maximum), merges templates by language, defaults to keeping existing values and skips open drafts. Replacing conflicts and restoring Wandbox each require explicit confirmation. A changed value during confirmation cancels the write. Submission, judge and transient runner records are outside the backup schema. |

## Reused behavior and local dependencies

P2 already supplied language grammars, find and replace, undo, word completions, IME, model lifecycle and the draft adapter. P3 supplied per-document clangd sessions, current-version request handling, cancellation, discovery, local header validation and bounded restarts. P1 supplied compiler selection, source snapshots, runner limits, process control and the bounded cache. This phase extended those entry points. The configurable timeouts use the existing wire field. The popup still owns settings, and compiler messages remain in the existing terminal.

The extension bundles every runtime asset. The build checks the six upstream MIT attribution blocks and includes the package notice. The offline rebuild records SHA-256 for each packaged asset. Existing upstream attribution and P3.5’s documented fork permission continue to apply. ### Reproduction

Run in this worktree on Windows with the repository’s test dependencies and an installed Korean two-set input layout for the physical IME check. Point `CBOJ_TEST_PYTHON` to the installed interpreter. The browser helper computes the shared directory from `git rev-parse --path-format=absolute --git-common-dir`. It holds `system-resources.lock` with `OpenOrCreate / ReadWrite / FileShare.None` for the full registered-host or foreground operation. Each registered run uses a private host name, staged extension, native temp root and disposable Chrome profile. The helper removes its own registry entry on exit. Offline runs use the isolated alias without any registration.

```powershell
npm.cmd ci --prefix tests/p0
npm.cmd ci --prefix tools/monaco
npm.cmd run build --prefix tools/monaco
foreach ($suite in 'p0','p1','p2','p3','polish','legacy','ime') {
    ./tests/p0/p41-verify.ps1 -Suite $suite
}
node tests/p0/p41-upgrade.mjs
foreach ($test in 'native_test','native_p1_test','native_p3_test','native_polish_test') {
    & $env:CBOJ_TEST_PYTHON -X utf8 -B "tests/p0/$test.py"
}
```

For the before/after timing fixture, extract `f5fd0b4` to a disposable directory and pass its path as `-Baseline` to `p41-verify.ps1 -Suite timing`. Repeat `-Suite timing` against the current extension. A manual fixture check can open the nested C++ draft, scroll into `sum`, choose a parent or sibling in the breadcrumb and toggle Alt+Z. Then run a deliberate local compile error, activate its location, and format and undo. Backup can be checked with a disposable draft open in two tabs. The safe merge keeps the open draft, and an explicit replacement of a closed conflict prompts for confirmation.

## Remaining limits

- Semantic outlines and occurrence identity follow P3’s C++ analysis support. C, Python and a C++ workspace without a capable clangd use file-only breadcrumbs and lexical occurrences. Incomplete C++ can temporarily have a shorter outline while clangd rebuilds.
- GCC versions without the byte-column option and old MSVC hosts can provide ambiguous coordinates on lines with tabs or non-ASCII text. The fallback opens the correct line at column one in those cases. Header-file diagnostics remain readable in the log. Installed Korean IME and real compiler checks cover this Windows installation.
- An older host can still edit, complete and run with its supported features. New formatting requires the updated host and installed clang-format. Users select any external runner explicitly. A backup is a local plaintext JSON document.
- P4-only storage and UI behavior require the combined revision. Authenticated BOJ submission and external Git integration remain owner-initiated production checks. All development submission and judging activity used local fixtures.
