## Integration points for P4.1

| Area | P4 contract and merge considerations |
| --- | --- |
| Monaco model and frame | `content/editor.js` retains the nonce-bound runtime port and zero-based draft cursor contract. The frame still owns one editor and one model at a time. Compose visual and editor options in `MonacoWorkspace.configure()`. Dispose model-specific rendering and subscriptions in `suspend()`. P4 forwards clangd diagnostic positions and a bounds-checked `jump` action through this existing port. |
| Completion and clangd | `editor/snippets.js` supplies model-scoped Monaco snippets to both the ordinary provider and the exclusive C++ semantic provider. C++ results retain clangd text edits and snippet flags. The last complete response is reusable only at the same version and cursor. Edits and session shutdown invalidate it. Analysis protocol 1, UTF-16 coordinates, draft limits, handshake, cancellation and allowed LSP methods retain their P3 contracts. |
| Settings | `shared/defaults.js` defines sync keys `powerMode`, `powerPreset`, `powerIntensity`, `powerShake` and `shortcutProfile`. Preserve the existing `editorTheme` preference when adding theme IDs. User snippet bodies live in local `workspaceSnippets` with `cpp`, `c` and `py` families. Their placeholders use Monaco's existing snippet controller. |
| Cases and layout | Reuse `cases:<pid>` with optional `name` and `compare`. A legacy empty expected value means run-only. Explicit `compare: true` permits a checked empty expectation. Only the worker mutates case records and serializes field-level updates from multiple tabs. A 66-case collection crosses the 64-input native message boundary in saved order. Larger batches use the same connection and compilation cache. `selectedCase:<pid>` and `panelTab:<pid>` restore selections. The existing `cbojLayout` gains collapse and maximize flags. |
| Native host | Runner protocol 2, install identity and manifests remain compatible. P4 changes local clangd resource discovery and the private per-session PCH location in `host/clangd_tools.py`. Integrate new native features through the existing schema and capability boundaries. Keep P4's private temporary directory, header validation and process-tree cleanup. |
| Workspace CSS and effects | Host-page controls are scoped to `#cboj-panel`. The original statement remains in the page. Frame options and typing effects belong to the extension document. `editor/power-mode.js` owns the transient canvas, counter, input listeners, timer and frame only while enabled. It draws at most 96 particles and caps its bitmap at 1920×1200. It clears on reduced motion, composition, scroll, blur, visibility changes and disposal. |
| Submission ownership | `shared/submission-sessions.js` is the only writer of managed form and origin records in session storage. It routes messages to the owning problem tab. It only prefills a validated official form. Two unbound forms on the same account and problem require a specific submission ID before associating a result. An ambiguous status view offers the user's history. |

The local review branch does not change the fork's published installation or default branch. P4.2 owns combined publication after checking the independent P4.1 marker and commit.

## Installation and manual review

Load the checkout containing `manifest.json` at `chrome://extensions` with Developer mode enabled. For local tools on Windows, run `host/install.bat`. For an existing toolchain and Chrome-only registration, use `powershell -ExecutionPolicy Bypass -File host/install.ps1 -RegisterOnly -ChromeOnly`. Reload the extension and the problem tab after an upgrade. For rollback, close affected tabs, restore the previous extension files and rerun that version's register-only installer. Keep the extension ID and browser profile when retaining drafts. [Installation guide](../../README.md#installation)

1. Open the local problem fixture, add a case, enter input and expected output, then run just that case. Change the expected output and inspect the highlighted line and raw streams. Reopen the problem and check the selected tab and saved input.
2. Save a language-specific snippet in the popup. In that language, type the prefix, open completion, accept the snippet and tab through its placeholders.
3. Enable Power Mode, select a preset and type a comment. Turn on reduced motion or disable the feature and continue typing. Open the diagnostics pane and activate a C++ error to navigate to its source.
4. Use the fixture suites for submission prefilling, focus return, status changes and cleanup. Production submission and external Git integration are reserved for ordinary, owner-initiated problem solving. The owner personally completes any production CAPTCHA and final submission.

Reproduction uses `python -B tests/p0/native_test.py`, `native_p1_test.py` and `native_p3_test.py` in the same directory. The real IME test is `node tests/p0/windows-ime.mjs`. Use the shared exclusive lock for installation, foreground input and checks that depend on the currently registered native host.

Repetition exposed several issues. A case could receive text intended for a newly added tab before its asynchronous creation completed. Creation now locks the old fields until the selected case is ready. A direct Wandbox fixture covers the independent terminal path. An MSVC capability probe timed out during concurrent toolchain testing and passed on the serial repeat. The terminal assertion now compares stdout and stderr separately because their OS pipes can interleave. The initial physical IME trial received extra copy/paste keystrokes before composition, as recorded in earlier P3 testing. The locked repeat produced the expected Korean text, save, find and replace behavior. No automated test made a production BOJ submission, or clicked the final submit button.
